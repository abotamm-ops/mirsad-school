# رسائل العملاء والاشتراك — المدارس فقط

إضافة المدارس 2.9.37 وخدمة المالك 2.9.38. لا تغييرات على النسخة الشخصية.

## ما جُهز
- لوحة مالك لنشر حتى خمس رسائل نصية نشطة، مع عنوان ونوع ومدة 1–30 يومًا، وإخفائها لاحقًا. تعرض الإضافة الرسائل بعد المزامنة عند فتحها، مرة لكل رسالة في تلك الفتحة، دون تنفيذ HTML ودون مقاطعة حوار مفتوح. لا يوجد ادعاء بأن كل عميل قرأ الرسالة.
- صفحة /schools/subscription.html، متاحة باليوزر والرقم السري حتى عندما يُحظر الرصد. جلسة الحساب المحظور تقتصر على الاشتراك، ولا تفتح التقارير أو إعدادات الرصد.
- البنك المحوّل منه، الاسم المختصر، المبلغ، رقم الحساب، وفاتورة PDF/Word/PNG/JPG/WebP حتى 4 MiB. فحص الحجم والترويسة لا يثبت السداد؛ التفعيل قبل المراجعة قرار المالك المقصود.
- تفعيل نفس الحساب عند نجاح رفع الإثبات: أسبوع 50 ريال، شهر 100 ريال، شهران 200 ريال، أو 150 ريال أثناء العرض الفعلي المحدد زمنيًا.
- الدفع مغلق افتراضيًا، والعرض بلا موعد افتراضي. لا تُشغّل تحصيلًا أو عدادًا أو حظرًا جماعيًا بمجرد النشر.
- يتطلب فتح الدفع اسم مقدّم الخدمة وبريد الدعم وتأكيد المالك أنه راجع الشروط. الشروط صياغة أولية ولا تمثل استشارة قانونية أو ضمانًا للإنفاذ.
- السعر يُحجز 15 دقيقة بحصة خادم مرتبطة بالحساب؛ عرض عام منتهٍ لا يعيد العداد، وتبقى الحصة القديمة صالحة حتى انتهاء مهلة السعر.
- موافقة صريحة غير محددة مسبقًا، مع حفظ نسخة الشروط والوقت والبريد وهوية المقدّم ضمن الإثبات.
- التفعيل مُعلّم pending. ملف الفاتورة محفوظ في مساحة خاصة بالخدمة دون روابط مشاركة عامة؛ لا يُعاد الملف إلا لمالك مخوّل عبر API.
- طلب الرفع له UUID، والإعادة لا تمدد المدة مرتين. إثبات واحد بانتظار المراجعة للحساب، ورفض استعمال نفس الملف مجددًا. المراجعة لا تنفذ محتوى المرفق.
- الاعتماد يفك حظر صاحب الإثبات دون تمديد جديد. الرفض يحظر الحساب مع ملاحظة المالك، ويمنعه من إعادة تفعيل نفسه بملف آخر؛ التفعيل اليدوي بعد تأكيد السداد يعيد الحساب نفسه.
- التفعيل المدفوع يضيف المدة إلى الاشتراك المدفوع المتبقي؛ التجربة المجانية ذات التاريخ البعيد لا تدخل في الحساب. الشهران يحسبان إلى الشهر الهدف مرة واحدة دون خسارة أيام بسبب المرور بفبراير.

## البناء
يتطلب ملف /tmp/mirsad-commercial/owner-2.9.21.gs الخاص بالمالك. لا ترفعه للمستودع.
```
python3 commerce/build.py
node commerce/service.test.cjs
node commerce/browser.test.cjs
python3 commercial-simple/build.py --extensions-only
python3 commercial-simple/package.py
python3 commercial-simple/package-owner-offline.py 2.9.38
```
البناء الكامل commercial-simple/build.py من الأساس القديم يستدعي commerce/transform كذلك، لكن لا تشغّله بلا الأساس الخاص الصحيح. بناء الإضافة فقط مستقل عن السكربت.

## نشر وتشغيل
1. انسخ خدمة المالك الجديدة إلى مشروع المدارس الحالي وحدث النشر الحالي بإصدار جديد؛ أبقِ الرابط والخصائص.
2. انتظر اكتمال Render للصفحات ولوحة المالك.
3. حدّث الإضافة عند العملاء إلى 2.9.37 مع الاستبدال في مكانها وتحديث ↻، دون حذفها. العملاء القدامى لا يعرضون الرسائل أو رابط رفع الفاتورة حتى التحديث.
4. من لوحة المالك افتح رسائل العملاء والاشتراكات؛ انشر فقط ما تقصده. لا تُنشر رسائل أثناء الاختبارات.
5. للدفع: أدخل هوية المقدّم وبريد الدعم والحسابات البنكية، راجع الشروط قانونيًا، ثم افتح الدفع عندما تريد. العرض يحتاج تاريخًا وساعة فعلية بتوقيت السعودية؛ يبقى مغلقًا إلى أن تحدده.
6. جرّب حساب مدرسة واحدًا قبل فتح التحصيل للعموم؛ لم نجرب تحويلًا بنكيًا أو نشر Apps Script حيًا من هذه البيئة.

مراجعة متجر Chrome السابقة لنسخة 2.9.31 لا تُحدَّث تلقائيًا بهذه الحزمة. لا تلغِ المراجعة أو تعد بإصدار متجر محدث دون فعل نشر مستقل.
