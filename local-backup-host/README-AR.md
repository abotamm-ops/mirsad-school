# حفظ مرصاد خارج التنزيلات — Windows

الإضافة 0.6.3 تحفظ الصور والنتائج في طابور محلي دائم، ثم ينسخها هذا المساعد إلى **G:\Data Copy وK:\Data Copy معًا**. عند غياب أحدهما أو فشل الكتابة أو تجاوز مهلة القرص، ينشئ نسخة بديلة في **C:\Data Copy**. داخل كل قرص مجلد يومي `توثيق غياب YYYY-MM-DD` وفيه صور PNG ونتائج JSON. لا يغيّر هذا المساعد إعداد تنزيلات Chrome ولا يرفع أي بيانات إلى الإنترنت؛ ربط Drive مستقل.

## تثبيت مرة واحدة

1. حدّث ملفات الإضافة في مجلدها المثبت نفسه إلى 0.6.3، ثم اضغط إعادة تحميل في `chrome://extensions`. لا تحذف الإضافة لتحتفظ بالصور المعلقة والإعدادات.
2. انسخ معرّف إضافة مرصاد من `chrome://extensions` (فعّل وضع المطوّر). يظهر أيضًا في الإضافة، تبويب Drive، قسم النسخة المحلية.
3. افتح مجلد `local-backup-host` وشغّل `Install.cmd`، ثم الصق المعرّف واضغط Enter. ينسخ برنامج المساعد المرفق، ويُسجله لهذا المستخدم دون طلب صلاحية مسؤول. يستخدم Windows PowerShell المضمن في Windows؛ لا يحتاج تطبيق Teams أو Python أو أدوات بناء. المصدر Go مرفق للمراجعة.
4. في الإضافة افتح Drive واضغط «فحص مساعد الحفظ وإعادة النسخ». يعرض المسارات التي نجحت الكتابة فيها. افحص حصة، ثم افتح مجلد اليوم وتأكد من الصورة والنتيجة. لا يعتبر مجرد تثبيت المساعد نجاح نسخ صورة.

إذا منع Windows إنشاء `C:\Data Copy`، أنشئ هذا المجلد يدويًا وأعطِ حساب Windows المستخدم صلاحية الكتابة فيه. لا تشغّل Chrome كمسؤول. عند فشل الأقراص كلها، تبقى الملفات داخل الإضافة ويعاد النسخ كل دقيقة؛ تظهر رسالة الفشل بدل الادعاء بنجاح الحفظ. لا تحذف الإضافة أو بياناتها أثناء وجود ملفات معلقة.

الصور القديمة التي نزلت قبل 0.6.3 لا تُنقل تلقائيًا؛ انقل مجلدها يدويًا إذا أردت الاحتفاظ بها. تصدير CSV الاختياري ما زال يعرض نافذة «حفظ باسم»، ويمكن اختيار G أو K أو C. لم تعد صور الإثبات الجديدة تستخدم Chrome Downloads.

## التحقق والحدود

- المساعد لا يقبل مسارًا من الصفحة أو أمرًا عامًا؛ مساراته ثابتة G وK وC، ولا يقبل إلا تاريخًا واسم صورة بسيطًا وPNG للغائب أو غير المحسوم ونتيجة JSON.
- تتحقق الكتابة بمقارنة SHA-256 قبل اعتماد الملف؛ الكتابة مؤقتة ثم إعادة تسمية. الإعادة لا تكرر الملف نفسه ولا تستبدل ملفًا مختلفًا موجودًا.
- لكل محاولة قرص مهلة ثانيتين؛ إذا تأخر القرص قد تكتمل عليه نسخة إضافية أثناء إنشاء البديل. لا يُحذف الطابور إلا بعد تأكيد النسخ المطلوبة أو البديل C.
- اختبارات التطوير تحاكي تعطل الأقراص. يلزم اختبار التثبيت والأقراص G/K/C على جهاز Windows الحقيقي؛ لا توجد هذه الأقراص في بيئة التطوير Linux.
- لإزالة المساعد فقط شغّل `Uninstall.ps1`. لا يحذف نسخ Data Copy.

## إعادة البناء من المصدر

Go 1.23 أو أحدث، دون مكتبات خارجية:

```sh
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o MirsadBackupHost-amd64.exe .
GOOS=windows GOARCH=386 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o MirsadBackupHost-386.exe .
```

ملفا EXE موجودان في حزمة التنزيل الجاهزة، وليسا مطلوبين داخل مصدر Git.
