# مشروع راصد — ملف تسليم المالك

هذا مشروع خاص بالمالك، وليس حزمة العملاء. لا ترسل هذا المجلد للمدارس، ولا تنشر مجلد BACKEND أو مفاتيح مشاريع Google أو بيانات حسابات العملاء.

ابدأ بملف LATEST_SESSION.md؛ يوضح آخر المحادثة والطلب الذي لم يكتمل.

## اقرأ بهذا الترتيب
1. AI_HANDOFF.md: نقطة البداية لأي مساعد أو مطوّر.
2. CURRENT_STATE.json: الإصدارات وحالة النشر المعروفة.
3. PROJECT_MAP.md: أين يوجد كل جزء.
4. PENDING_REQUIREMENTS.md: المتطلبات المؤجلة؛ لا تعتبرها منفذة.
5. OPERATIONS.md: البناء والاختبارات والنشر.

## أهم فرق
- نسخة المدارس مختلفة عن النسخة الشخصية. لا تستبدل إحداهما بالأخرى.
- تحديث صفحات الموقع لا يحتاج تحديث الإضافة غالبًا.
- تغيير خدمة Google Apps Script يحتاج تحديث النشر الحالي مع إبقاء رابط الخدمة وخصائص المشروع.
- ملفات EXE هي مكونات Windows. اختبارات Linux لا تثبت نجاح التشغيل الميداني على Windows.
- البيانات المصطنعة محاكاة معلنة، وليست فحصًا حقيقيًا لمدرستي أو تيمز.

المجلد BACKEND يحتوي نسخًا كاملة من كود خدمة المالك لمتابعة التطوير. لا يحتوي تصديرًا حيًا لخصائص مشروع Apps Script أو حسابات العملاء. النسخة الفعلية من المشروع وخصائصه تبقى في حساب المالك على Google. احتفظ بنسخة احتياطية مستقلة منها.
