# مساعد مرصاد 1.2.0 — واجهة مرصاد الجديدة

يتطلب Windows 10/11 بمعمارية 64 بت، وGoogle Chrome، وإضافة مرصاد المدرسية الموجودة بالفعل. لا يحتاج تثبيتًا أو صلاحية مسؤول. يستخدم Windows PowerShell المضمن داخليًا دون إظهار نافذة أوامر. الملف التنفيذي غير موقّع بشهادة تجارية، وقد يعرض Windows تحذير ناشر. لا يغير إعدادات حماية الجهاز أو التشغيل التلقائي.

واجهة عربية بألوان كحلية وخضراء، وبطاقات للحالة ووظائف الحماية، وزوايا مستديرة وأيقونة رادار. زر × العلوي يوقف المساعد ويغلقه، وزر − يخفي اللوحة بجانب الساعة مع استمرار الحماية. يمكن سحب النافذة من عنوان مرصاد. تغيير الواجهة لا يغير عمل الرصد أو يتطلب تحديث الإضافة أو السكريبت إذا سبق تحديثهما.

## الاستخدام

1. حدّث الإضافة إلى 0.6.73 في مجلدها الحالي دون حذفها. إذا سبق نشر سكريبت 0.6.72 فلا تحتاج إعادة نشره لهذا التغيير.
2. فك الضغط ثم افتح **MirsadChromeGuardian.exe**. لا تحتاج فتح Start.cmd أو ملف PowerShell. فتح التطبيق يبدأ المراقبة تلقائيًا، مع زر «تشغيل» لإعادة المحاولة عند خطأ.
3. يختار ملف Chrome الذي عليه إضافة مرصاد، ويسألك إن كانت الإضافة في عدة ملفات. يفتح نافذة مرصاد ويكبّرها ويثبّتها فوق النوافذ العادية، مثل إيدج. بعد ظهور النافذة تختفي لوحة المساعد إلى أيقونة الدرع بجانب الساعة، وقد تكون داخل سهم الأيقونات المخفية.
4. شغّل الرصد من الإضافة كالمعتاد؛ المساعد لا يبدأ رصدًا موقوفًا أو يتجاوز تسجيل الدخول. تفتح الإضافة 0.6.73 فحوص تيمز في نافذة المساعد ذاتها حتى لا يحجب تثبيت مرصاد اجتماع المعلم أو صورة إثباته. لا تنقل تبويب مرصاد الخاص بالمساعد إلى نافذة أخرى أثناء تشغيله.
5. لإيقافه: انقر أيقونة الدرع مرتين لفتح اللوحة، ثم اضغط **«إيقاف وإغلاق»**. أو اضغط بالزر الأيمن على الدرع واختر الإيقاف. يتوقف منع السكون وإعادة الفتح ويُلغى تثبيت النافذة، وتبقى Chrome وبيانات الرصد مفتوحة. إيقاف الرصد نفسه يتم من الإضافة.

النافذة التي يفتحها التطبيق تحمل علامة guardian في رابطها، ليعرفها الرصد. لا تُنسخ هذه العلامة إلى روابط الحصص. لا تُفتح روابط خارج صفحة مرصاد الثابتة، ولا يُنشأ ملف Chrome جديد.

## ما يفعله وحدوده

يفحص النافذة كل ثانيتين، ويعيد تكبيرها إن صُغّرت ويفتحها مجددًا إن أُغلقت. إذا فشل الفتح خلال 45 ثانية يظهر السبب ويتوقف بدل إنشاء نوافذ متكررة. يطلب إبقاء الشاشة والنظام مستيقظين أثناء عمله فقط؛ لا يغير السجل أو إعدادات الطاقة الدائمة. تشغيل التطبيق مرتين لا ينشئ مراقبين متنافسين.

التثبيت فوق النوافذ العادية ليس قفلًا أمنيًا أو وضع كشك: لوحة التحكم الخاصة بالمساعد تظهر عمدًا عند طلبها لإيقافه. رسائل النظام على سطح المكتب الآمن، Win+L، وسياسات المدرسة، والإطفاء وتعليق النظام لا يمنعها. لا يضمن تسلم صوت التنبيه عند إغلاق صفحة مرصاد على جهاز الاستماع. الإضافة 0.6.72 وما بعدها توفر تنبيه قفل الجلسة بشكل مستقل.

## تجربة على جهاز الرصد

افتح التطبيق وتحقق من ملف Chrome الصحيح. افتح إيدج وتأكد أن نافذة الرصد فوقه، ثم صغّر نافذة الرصد وأغلقها للتحقق من التكبير وإعادة الفتح. افحص معلمًا تجريبيًا وتحقق أن تيمز يفتح في نفس النافذة وأن صورة الإثبات سليمة. أوقف المساعد من اللوحة وتأكد أن Chrome لم يعد ثابتًا فوق النوافذ ولا يُعاد فتحه. الاختبار الفعلي على Windows مطلوب قبل الاعتماد دون متابعة.

## التحقق والبناء

فُحصت صياغة PowerShell وتعريفات Windows API. شُغلت دالة المراقبة الفعلية بمحاكاة النوافذ والتكبير والإغلاق، واختُبر إلغاء التثبيت وطلب منع السكون عند إغلاق اللوحة. اختبارات Go تتحقق من الملف المضمن ومسح الملف المؤقت، وبُني EXE لواجهة Windows الرسومية. اختبارات الإضافة تتحقق من توجيه تيمز لأحدث نافذة خاصة بالمساعد دون نقل فحص جارٍ. لا تتوفر جلسة Windows فعلية في بيئة التطوير.

بأدوات Go 1.23 أو أحدث، داخل مجلد chrome-guardian:

```
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-H=windowsgui -s -w" -o MirsadChromeGuardian.exe .
```
