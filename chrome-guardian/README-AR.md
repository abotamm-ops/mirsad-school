# مساعد إبقاء مرصاد مفتوحًا — Windows

مساعد مستقل يعمل أثناء تشغيله فقط. لا يحتاج صلاحية مسؤول ولا تغيير إعدادات ويندوز أو تثبيت إضافة جديدة. يتطلب Windows 10/11 وGoogle Chrome وإضافة مرصاد المدرسية الموجودة بالفعل. النسخة الأولى تحتاج تجربة فعلية على جهاز Windows قبل اعتمادها للرصد دون متابعة.

## التشغيل

1. فك الضغط في مجلد ثابت. أبقِ إضافة مرصاد في مكانها وملف Chrome المعتاد؛ لا تحذفها ولا تستخدم ملف متصفح جديدًا.
2. افتح `Start.cmd`. يستخدم Windows PowerShell الموجود في ويندوز؛ سماح تشغيل السكريبت يخص هذه العملية فقط ولا يغيّر سياسة الجهاز الدائمة.
3. يكتشف ملف Chrome الذي يحتوي معرّف إضافة مرصاد المدرسية. إذا وُجدت في عدة ملفات، يسألك عن الملف المطلوب، ولا يختار ملفًا آخر تلقائيًا.
4. يفتح نافذة جديدة لصفحة الرصد في ملف Chrome نفسه. تظهر أيقونة درع بجانب الساعة، وقد تكون داخل سهم الأيقونات المخفية. هذه النافذة هي التي يراقبها.
5. شغّل الرصد من الإضافة كالمعتاد. فتح الصفحة وحده لا يبدأ الرصد، ولا يصلح إعدادًا ناقصًا أو جلسة تسجيل دخول منتهية.

## ما يفعله

- يفحص نافذة مرصاد كل ثانيتين. إذا أُغلقت يعيد فتح نافذة لصفحة الرصد في ملف Chrome ذاته.
- إذا صُغّرت النافذة أو أُعيد حجمها، يعيد تكبيرها. لا يفرض تركيز لوحة المفاتيح باستمرار ولا يغلق نوافذ المستخدم الأخرى.
- يطلب من ويندوز إبقاء الشاشة والنظام مستيقظين أثناء تشغيل المساعد، ويحرر الطلب عند إيقافه. لا يعدّل سجل النظام أو سياسة القفل أو إعدادات الطاقة الدائمة.
- إذا تعذّر فتح النافذة، يعرض السبب ويتوقف بدل فتح نوافذ بلا نهاية. ينتظر تحميل النافذة حتى 45 ثانية. لا تشغّل نوافذ Chrome أخرى بالتزامن مع بدء اكتشاف النافذة.
- لا يقرأ بيانات الطلاب أو كلمات المرور، ولا يرفع ملفات أو يرسل بيانات إلى خدمة جديدة. يفتح رابط الرصد الثابت فقط.

الإضافة مسؤولة عن استعادة موضع الرصد المحفوظ بعد عودة Chrome؛ المساعد لا يغيّر نتائجه أو دوراته ولا يبدأ رصدًا موقوفًا. استمرار الرصد بعد إغلاق المتصفح يحتاج التحقق من إعدادات الاستئناف وصلاحيات الإضافة على الجهاز.

## الإيقاف

اضغط بالزر الأيمن على أيقونة الدرع بجانب الساعة ثم «إيقاف المساعد — إبقاء Chrome مفتوحًا». يتوقف منع السكون وإعادة الفتح، وتبقى نافذة Chrome وبيانات الرصد كما هي. لإيقاف الرصد نفسه استخدم الإيقاف في الإضافة أيضًا. إغلاق نافذة الأوامر التي شغّلت المساعد يوقف العملية كذلك.

لا يضيف المساعد تشغيلًا تلقائيًا أو خدمة دائمة. شغّل Start.cmd بعد تسجيل الدخول إذا احتجته. تشغيل المساعد مرتين يعرض أنه يعمل بالفعل بدل إنشاء مراقبين متنافسين.

## حدود واضحة

هذا يعيد الفتح والتكبير؛ لا يمنع ضغط زر الإغلاق أو التصغير نفسه. لا يمنع الإطفاء الفعلي أو قفل المستخدم أو الخروج من ويندوز أو سياسات المدرسة الإلزامية أو انقطاع الكهرباء أو تعليق المتصفح. إبقاء الشاشة مفتوحة لا يؤمّن الجهاز من الاستخدام. المنع الصارم للإغلاق والاستخدام الآخر يحتاج وضع الكشك المُدار في ويندوز.

## تجربة القبول على جهاز الرصد

بعد تشغيل المساعد تأكد أن نافذة مرصاد مفتوحة في ملف إضافة الرصد نفسه. صغّر النافذة وتحقق أنها تتكبر، ثم أغلقها وتحقق من إعادة فتحها. افحص حصة تجريبية للتأكد من استئناف الإضافة وعدم تكرار دورة مكتملة. جرّب الإيقاف من أيقونة الدرع، ثم أغلق النافذة وتأكد أنها لا تُفتح من جديد. اختبر استمرار الشاشة أثناء انتظار دورة، مع مراعاة أن سياسات القفل الإلزامية قد تتغلب على طلب منع السكون.

تحقق التطوير: فُحصت صياغة PowerShell وجُمعت تعريفات Windows API، وشُغّلت دالة المؤقت الفعلية بمحاكاة نوافذ Chrome: التمييز عن نافذة أخرى، حفظ ملف المتصفح في الأمر، التكبير بعد التصغير، وإعادة الفتح بعد الإغلاق دون تكرار الفتح أثناء الانتظار. لم يُختبر Windows Forms أو طلب الطاقة على نظام Windows فعلي ضمن هذه البيئة.
